# Abstract 

## 1. 背景 Background

### VLM（Vision-Language Model）
* 大规模多模态数据预训练的模型
* 能理解：

  * 图像（Vision）
  * 文本（Language）

例如：

```
图片 + 指令
      ↓
理解任务
```

因此成为机器人智能的重要基础。

---

## 2. 现有方法：VLA

### VLA（Vision-Language-Action）

将 VLM 扩展到机器人控制：

```
视觉 Image
+
语言 Instruction
        ↓
       VLA
        ↓
机器人动作 Action
```

目标：

让机器人能够根据自然语言完成任务。

---

## 3. 当前问题 Problems

### 问题1：模型太大

现有 VLA：

* 数十亿参数
* 训练成本高
* 需要大量 GPU
* 难以部署到真实机器人

### 问题2：数据来源有限

传统数据：

* 学术实验室
* 工业机器人

缺少：

* 普通用户采集的数据
* 廉价机器人平台数据

---

## 4. SmolVLA 提出

论文提出：

### SmolVLA

一个：

> 小型、高效、社区驱动的视觉-语言-动作模型

目标：

降低：

* 训练成本
* 推理成本

同时保持：

* 较强性能

---

## 5. 核心创新 Contributions

### (1) 小模型设计

特点：

* 单 GPU 可训练
* 消费级 GPU 可部署
* 甚至 CPU 可运行

目的：

降低机器人 AI 使用门槛。

---

### (2) 异步推理框架

传统：

```
感知
 ↓
预测动作
 ↓
执行
```

SmolVLA：

```
感知/预测
      +
动作执行

并行运行
```

提高：

* 响应速度
* 控制频率

---

### (3) 分块动作生成

不是一次预测一个动作：

```
动作1
动作2
动作3
```

而是：

```
动作序列:
[动作1,动作2,动作3...]
```

提高机器人连续控制能力。

---

## 6. 实验结果

SmolVLA：

* 在模拟机器人环境测试
* 在真实机器人平台测试

结果：

> 参数规模小很多，但性能接近大约 10 倍规模的 VLA 模型。

---

## 一句话总结

> SmolVLA 通过缩小 VLA 模型规模、利用社区机器人数据以及优化推理流程，使机器人视觉语言控制模型能够在普通计算设备上运行，同时保持接近大型模型的性能。

# Introduction
## 研究背景
LLM（Large-Language Model)（像ChatGPT）已经很强了，于是想把这个能力扩展到VLM(Vision-Language Model)，再进一步扩展到VLA(Vision-Language-Action Model)
因为VLM已经学习了大量的世界、视觉、语言知识，因此可以作为机器人智能的大脑

## 传统机器人学习的问题
传统训练：从零开始
```txt
机器人
↓
大量机器人数据
↓
学习动作
```
问题：
- 数据不足
- 泛化能力差
机器人面对不同的物体、环境、位置，容易失败。
例如：
训练：拿红色杯子
测试：蓝色杯子
可能会失败

## VLA模型出现
```txt
视觉 Vision

       \
        \
         VLA
        /
语言 Language

       ↓

动作 Action
```
输入：图像Image + 语言Instruction + 机器人状态Robot State
输出：机器人的动作

但同时，现有VLA模型太大+数据不开放

## 提出SmolVLA
小型、高效、开源的VLA模型

## SmolVLA三个主要贡献
### 轻量化架构
- 跳过VLM部分层
- 减少视觉token
- 使用小型VLM，降低参数量
### 社区数据训练
### 异步推理
传统：
```txt
预测动作
↓
执行
↓
再次预测
```
问题：机器人等待

SmolVLA:**预测和执行并行**
```txt
线程1：
预测下一组动作

线程2：
执行当前动作
```
提高控制速度和响应能力

## 总结
> Introduction 主要说明：虽然 VLM 给机器人带来了强大的视觉和语言理解能力，但现有 VLA 模型参数巨大、成本高、数据封闭，因此 SmolVLA 提出一种小型、开源、高效的 VLA，通过轻量架构、社区数据和异步推理降低机器人 AI 使用门槛。
