# 前言

初中时地理老师会给我们放《航拍中国》，直升机视角下的山川湖泊、人文习俗给小小的我带来了极大的震撼与憧憬。但受限于学业繁重与父母对旅行并不感冒，所以在上大学前我也只是在小学的时候去过成都和昆明。高三后期最难熬的时候大家都在讨论高考假怎么旅游，但是高考完后被母亲无情泼了盆冷水。于是那个本该是最轻松最长最没有顾虑的暑假，我在家里面一边被迫听网课一边羡慕朋友圈的好朋友都在到处旅游。（虽然那时是因为还没有成年，但还是好可惜

后面来北京读书，最开始还是和几个高中好朋友有联系，但大家好像都比较胆小，国庆也只是约着在北京爬香山，没有人提出去别的地方旅游（其实提出了也不敢）。

胆子开始变大是在大一上学期末的时候，和另一位在天津的同学约好去找她玩。但很遗憾的是他们学院临时通知周末有活动，我又实在不甘心，约了位舍友在早上六点坐高铁去了天津。但那次又因为前一天睡太晚了，在天津吃了顿很多种类的早餐后困得不行在地铁上一直睡，最后草草吃了顿晚饭就回北京了。

从小对“杏花春雨江南”有着很强的滤镜，再加上中传的读书周和五一连放（读书周景区没什么人），于是在五一前一个月和舍友约好五一去苏州玩，参考了很多教程做了一份满满当当的攻略，但很可惜的是舍友临时有事，自己玩又不好玩，于是在放假前一天给妹妹和妈妈买了去上海的机票。可能是和妹妹差三岁和母亲差辈分（有代沟），五一之行的景色是很美的，当然心情也很好，但总感觉差一点趣味。

所以直到那时我都没有经历过一次和同龄人出去旅游的经历。

暑期线下实践汇聚了从各个学校各个地区来的大一大二大三的学生，在可能一百多人中我们十多个人在机缘巧合之下组成了一队。最开始我以为大家可能就工作上进行一些简单的交流，其他时候安静干活不会再有任何交流，十多个陌生人在北京待几天后又回到自己的学校自己的生活。关系拉近是在一天晚上，大家莫名其妙地聊到了专业，聊到了学校。当然仅靠一天晚上就拉近距离是不可能的，但后面确实组内氛围没有那么压抑了。

我是一个不是很爱社交的人，大学读了一年也没把班上同学认全，打游戏碰到厉害的网友也只是加上好友就没了。如果你在暑假前告诉我我之后会和三个外校的不是高中同学的人玩得很好，我会觉得你一点也不了解我。

但我确实在这十五天重新感受到了久违的高中的社交感觉——大家每天从早上八点到会场一直到下午六点才离开，中间这么长的时间都在一起。大家莫名其妙开始聊天，之后互相感叹为什么这么难，偷偷在不想完成任务时溜出去打王者荣耀（四个人有三个辅助一个射手，还一直输）……第一次七个人去玩密室逃脱出来后意犹未尽，决定第二天再去玩一次，但可惜的是第二次就只有四个人了。

我也是一个对友情很悲观的人，线下结束回家的路上我有点遗憾，我们暑期的王者小分队+密逃小分队可能就这么随着线下实践的结束而冷清了，但好像一直活到了现在。缘分真是一个很奇妙的东西。

于是我们在国庆前计划我们的国庆之旅，六天五城，我感受了不一样的旅行体验。接下来就是正文了。

**（能和几个精力和消费习惯都相近的好朋友出去旅行真的很幸福）**

# 行程梳理

|日期|行程记录|
|---|---|
|10.2|去天津蓟县，下地铁时碰到鼠鼠；在天津吃羊汤，下午去九山顶玩，晚上回北京。|
|10.3|早上休息、收拾行李；下午坐高铁去沈阳，晚上吃刘牌牌烧烤。|
|10.4|早上坐高铁去本溪，租车前往关门山国家森林公园；晚上回沈阳去洗浴中心。|
|10.5|下午从沈阳租车开去营口。城区的海已经退潮，又开车五十多公里去找海；回酒店后在楼下打了一小时台球。|
|10.6|早上五点起床去鸟浪广场看红海滩和日出；坐高铁去长白山，中午到后放下行李，去露水河漂流。|
|10.7|爬长白山西坡看天池，去锦江大峡谷；晚上坐高铁回沈阳。|
|10.8|凌晨两点坐高铁回北京，早上六点到宿舍。|

# 10.2——天津蓟州

- 六点起床赶火车，在下地铁时碰到了小伙伴鼠鼠，我们在极限卡点中成功上车。一个多小时的车程，我俩一个“举头望明月”，一个“低头思故乡”，竟然也能在吵吵闹闹的火车上睡着了。

# 10.3——去沈阳

- 一直说着要收拾行李，最后在3号早上终于收拾完了；中午在大悦城找了家火锅店（山缓缓），只有漂亮没有饭，追求吃饱和性价比就算了。吃完火锅没赶上高铁，在发车前几分钟临时改签了。园长收拾东西时突然找不到房卡，最后到沈阳后从口袋里翻出来了。
- 去沈阳的高铁上网络竟然还不错，打了几把终极觉醒给园长展示了一手超标杨玉环。
- 到沈阳其实也才下午五六点但那边已经天黑了，在嘴哥的带领下我们去吃刘牌牌烧烤。好快乐，园长和嘴哥一直在烤肉，我什么都不用做专心品尝美食。碰到这种能做选择还会干活的好朋友就偷着乐吧

# 10.4——本溪

- 在小红书上看到本溪的枫叶很好看，我们又买了去本溪的高铁票，在本溪租了一辆又贵又臭的车开车去关门山森林公园，依旧嘴哥开车我们在车上睡觉。
- 花40坐小船欣赏了一公里的美景，又坐了一辆臭臭的景区大巴车上山，然后又花了应该两三个小时走下山。可能去的时间太早了，枫叶其实都没红但也挺好看的

# 10.5——营口
- 5号等我们睡醒收拾完租好车已经下午了，原定的去营口海边看日落的计划被迫改为在高速路上追晚霞。于是我们听着吵吵闹闹的歌，聊着乱七八糟的话题——像回到了小时候，一群人开心地叽叽喳喳坐上去春游的车。

- 吃完晚饭后天已经很黑了，但大家一直惦记着我说没看过海，带我在城区找海无果，于是驱车到五十多公里外的海滨公园，光明正大地走过门禁，打着手机手电筒在漆黑的有点寒冷的夜里寻找能够下到海边的路。因为没有灯光污染，我第一次看见这么多这么亮的星星，在海边捡贝壳时被海水浸湿了鞋子，海浪裹挟着的风有股淡淡的鱼腥味。
